# AGENT — Directives d’interaction pour le projet Inventra

Pour toute contribution au code, veuillez consulter le fichier  
[CONTRIBUTING.md](CONTRIBUTING.md) qui décrit les bonnes pratiques et la structure du code d’Inventra.

Les rapports de sécurité doivent respecter la politique définie dans  
[SECURITY.md](docs/SECURITY.md)  
et expliquer clairement comment ils s’inscrivent dans le  
[modèle de menace](docs/concepts/threat_model.md) d’Inventra.

## Règles strictes concernant l’usage de l’IA

- **Ne pas ouvrir de pull request sans revue manuelle préalable par un humain.**
- **Ne jamais soumettre de tickets (issues) générés automatiquement par une IA.**
- L’utilisation de contenu généré par IA dans les discussions d’issues ou de PR peut entraîner :
  - des violations du code de conduite,
  - des fermetures de tickets,
  - voire des bannissements du projet.

Inventra exige que toute contribution soit réfléchie, vérifiée et assumée par un contributeur humain.
