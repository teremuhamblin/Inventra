# SECURITY — Politique de sécurité Inventra

Inventra est un projet orienté fiabilité, sécurité et intégrité des données.  
Ce document explique comment signaler une vulnérabilité.

## Signaler une vulnérabilité
Les rapports doivent être envoyés via GitHub Security Advisories.

Chaque rapport doit inclure :
- Description détaillée de la vulnérabilité
- Impact potentiel
- Étapes de reproduction
- Interaction avec le modèle de menace (`docs/concepts/threat_model.md`)
- Correctif proposé (si possible)

## Délais de réponse
- 48h pour l’accusé de réception
- 7 jours pour l’analyse
- 30 jours pour le correctif

## Interdictions
- Ne jamais divulguer publiquement une faille avant correctif.
- Ne jamais utiliser l’IA pour générer un rapport de sécurité.
