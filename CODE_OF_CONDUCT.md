# CODE OF CONDUCT — Inventra

## Objectif
Garantir un environnement respectueux, professionnel et sécurisé pour tous les contributeurs.

## Comportements attendus
- Respect des autres contributeurs
- Communication claire et constructive
- Respect des règles de sécurité et de contribution
- Transparence dans les décisions techniques

## Comportements interdits
- Harcèlement, insultes, comportements agressifs
- Spam, publicité, contenu non pertinent
- Utilisation de contenu généré par IA dans les discussions techniques
- Tentatives de sabotage ou de diffusion de failles

## Sanctions
- Avertissement
- Suspension temporaire
- Bannissement définitif du projet

## Contact
Pour tout problème, contacter les mainteneurs via GitHub.
